¿Quién hace qué?

  1. Detecta el botón y graba el audio I2S (16 kHz · 16 bits · mono)
  2. Envía el WAV por HTTP POST con el token
  3. Valida el token, el formato y la duración
  4. STT: convierte la voz en texto
  5. LLM: genera la respuesta en español
  6. TTS: convierte la respuesta en voz
  7. Convierte el audio a WAV 16 kHz, guarda el log y lo devuelve
  8. Reproduce la respuesta por el MAX98357A
